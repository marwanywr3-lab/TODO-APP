# Tasks | مهامي

A simple bilingual (English / Arabic) to-do list with light and dark themes.
تطبيق قائمة مهام بسيط يدعم العربية والإنجليزية والوضعين الفاتح والداكن.

## Features | المميزات
- Arabic (RTL) and English (LTR), switchable instantly | عربي (من اليمين لليسار) وإنجليزي
- Light and dark themes, follows the system by default | وضع فاتح وداكن
- Add, complete, edit (double-click or Edit), delete, filter, clear completed
- Saved in the browser (`localStorage`), no backend, no build step

## Run locally | التشغيل
Open `index.html` in a browser. Or: `python3 -m http.server` then visit http://localhost:8000

## Deploy on GitHub Pages | النشر
1. Push this folder to a GitHub repository.
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`.
3. Your app will be live at `https://<username>.github.io/<repo>/`.
